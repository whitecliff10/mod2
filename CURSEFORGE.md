# CurseForge publishing kit

## Title

Everpulse — Living World Events

## Summary

Four supernatural world events transform nights, empower mobs, unlock sigils, champions, rituals, and a new global progression path.

## Categories

- Adventure and RPG
- Magic
- Mobs
- Utility & QoL

## Description

**The world has a heartbeat — and every few nights, you can feel it.**

Everpulse adds a global Vanilla+ progression system built around four rotating supernatural events. Verdant, Ember, Zephyr, and Umbral Pulses change player abilities, alter hostile mobs, and create limited windows for earning unique sigils.

Use the Pulse Compass to read the living calendar. Hunt pulse-touched champions during Umbral nights. Build a Pulse Altar and offer sigils for lasting blessings. Unite all four powers into the Worldheart — or spend your rewards on glowing thematic building blocks.

### Features

- Four rotating, configurable global events
- Event-specific player and monster effects
- Rare named champion enemies with enhanced health, speed, and damage
- Four collectible sigils and ritual blessings
- Pulse Compass with event forecast and countdown
- Endgame Worldheart reward
- Five new glowing blocks
- Four advancements
- English and Russian translations
- Dedicated-server support
- No required content libraries

### Requirements

Minecraft 1.21.1, NeoForge 21.1.249+, Java 21. Install on both client and server.
