# Everpulse — быстрый старт

## Сборка через GitHub

1. Создайте новый пустой репозиторий.
2. Загрузите **всё содержимое** папки Everpulse, включая `src` и `.github`.
3. Убедитесь, что в корне видны `src/main`, `.github/workflows`, `build.gradle` и `settings.gradle`.
4. Откройте Actions и дождитесь выполнения `Build Everpulse`.
5. Скачайте artifact `Everpulse-1.0.0`, распакуйте его и возьмите `everpulse-1.0.0.jar`.

Сборка специально проверяет наличие кода и метаданных внутри JAR. Пустой JAR не будет отмечен зелёной галочкой.

## Установка

Используйте Minecraft 1.21.1, NeoForge 21.1.249+ из ветки 21.1.x и Java 21. Положите JAR в папку `mods`. Не переименовывайте ZIP в JAR.

## Начало игры

Создайте Компас пульса из часов, редстоуна и осколков аметиста. Каждую третью ночь начинается один из четырёх пульсов. Убивайте обычных враждебных мобов во время события, чтобы получить сигилы. Во время Пульса мрака ищите светящихся усиленных чемпионов.
